Nexus (usage-billing) is the simplest way to get started with pay-as-you-go model access in Nexus.

Instead of managing separate API keys across multiple vendors, you sign in once, add **Nexus credits**, and select from available models directly in Nexus.

If you want a flat monthly subscription that offers 2-5x the usage on selected open coding models compared to standard API rate, use [NexusPass](/getting-started/nexuspass) instead. NexusPass is a separate provider in Nexus.

## Why use Nexus (usage-billing)

- **Fastest setup**: no manual API key copy/paste; access to 100+ models supported by Nexus
- **One account**: sign in once with Google, GitHub, or email
- **Pay as you go**: add Nexus credits and use one balance across supported models
- **Free options**: look for models tagged **FREE** in the selector

## How it works

Nexus (usage-billing) is the pay-as-you-go provider in Nexus. Add Nexus credits, then select **Nexus** wherever you configure your provider.

- **IDE Extension**: Go to IDE extension settings, set **API Provider** to **Nexus**, and sign in.
- **CLI**: Go to `/settings` and select **Nexus** as your provider.

## Credits and usage

- Add **Nexus credits** from your [Nexus dashboard](https://app.nexus.bot/dashboard)
- Credits are used on a pay-as-you-go basis when you select paid models through Nexus (usage-billing)
- View usage in Nexus Settings → **View Usage**
- Switch organizations in Nexus Settings → **Switch Organization**
