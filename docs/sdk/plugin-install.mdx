The Nexus CLI provides a `plugin install` command to install plugins from various sources. You can also load plugins programmatically via session config.

## CLI Installation

Use the `nexus plugin install` command to install plugins from file URLs, npm, git repositories, or local paths.

```sh
nexus plugin install <source> [options]
```

The shorthand `nexus plugin i` works as well.

### Install from a File URL

```sh
nexus plugin install https://github.com/nexus/nexus/blob/main/sdk/examples/plugins/weather-metrics.ts
nexus plugin install https://raw.githubusercontent.com/nexus/nexus/main/sdk/examples/plugins/weather-metrics.ts
```

Installs a single `.ts` or `.js` plugin file from an HTTPS URL. GitHub `blob` URLs are normalized to raw file downloads automatically.

### Install from npm

```sh
nexus plugin install --npm @scope/plugin-name
```

Installs the package from the npm registry into the Nexus plugin directory.

### Install from Git

```sh
nexus plugin install --git https://github.com/owner/repo.git
nexus plugin install --git github.com/owner/repo
```

Clones the repository (shallow, with blobless filter for speed) and installs its dependencies. The `.git` directory is excluded from the final install.

### Install from Local Source

```sh
nexus plugin install ./path/to/plugin.ts     # Single file
nexus plugin install /absolute/path/to/dir   # Directory with package.json
```

Supports both files and directories. Local installs copy the source, filter out `.git` and `node_modules`, and run `npm install` to resolve dependencies.

### Options

| Option | Description |
|--------|-------------|
| `--npm` | Treat the source as an npm package name |
| `--git` | Treat the source as a git repository URL |
| `--force` | Overwrite an existing plugin at the same path |
| `--json` | Output results as JSON (useful for scripting) |
| `--cwd` | Install to `<path>/.nexus/plugins` and resolve relative local paths from `<path>` |

### Examples

```sh
# Install a local plugin directory
nexus plugin install ./my-custom-plugin

# Install a single plugin file from GitHub
nexus plugin install https://github.com/nexus/nexus/blob/main/sdk/examples/plugins/weather-metrics.ts

# Install an npm package as a plugin
nexus plugin install --npm @nexus/plugin-sql

# Install from a GitHub repo
nexus plugin install --git https://github.com/my-org/my-plugin.git

# Force reinstall an existing plugin
nexus plugin install --force --npm @scope/plugin-name

# Use shorthand
nexus plugin i --git github.com/owner/repo
```

### Listing Installed Plugins

Installed plugins appear in the `plugins` section of your CLI config:

```sh
nexus config
```

### Find All Your Plugins from your file system

Project-scoped plugins live in the `.nexus/plugins/` folder at your workspace root. The CLI auto-discovers plugins from this folder when you run Nexus in that project.

```text
your-project/
├── .nexus/
│   └── plugins/
│       ├── my-plugin.ts
│       └── another-plugin/
└── ...
```

To add a single-file plugin to a project, install it with `--cwd`:

```sh
nexus plugin install https://github.com/owner/repo/blob/main/plugins/my-plugin.ts --cwd .
```

Global plugins are discovered from `~/.nexus/plugins/`, and Nexus may also discover plugins from the system Plugins folder. Use `--cwd .` when you want plugins to stay with a specific project.

## Programmatic Installation

### Using `pluginPaths` (NexusCore)

In SDK code, load plugins from file paths using the `pluginPaths` session config option:

```typescript
import { NexusCore } from "@nexus/sdk"

const nexus = await NexusCore.create({ clientName: "my-app" })

await nexus.start({
  config: {
    systemPrompt: "Analyze this project",
    // ...model/runtime config
    pluginPaths: ["/absolute/path/to/plugin.ts"],
  },
})
```

Plugin files must export an `AgentPlugin` as the default export. `pluginPaths` also accepts a package directory -- the SDK reads `package.json` and follows the `nexus.plugins` entries, so you can `npm install` once inside a package and iterate without re-running `nexus plugin install` on every edit.

### Using `plugins` (Agent Runtime)

When using the `Agent` or `AgentRuntime` directly, pass plugin instances in the `plugins` array:

```typescript
import { Agent } from "@nexus/sdk"
import { myPlugin } from "./my-plugin"

const agent = new Agent({
  providerId: "anthropic",
  modelId: "claude-sonnet-4-6",
  plugins: [myPlugin],
})
```

### Using `extensions` (NexusCore)

With `NexusCore`, use the `extensions` config array instead:

```typescript
import { NexusCore } from "@nexus/sdk"

const nexus = await NexusCore.create({ clientName: "my-app" })

await nexus.start({
  config: {
    systemPrompt: "Analyze customer records",
    extensions: [myPlugin],
  },
})
```
